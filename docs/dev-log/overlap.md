# Overlap / direction dev log (agent `overlap`)

Format: what AI produced -> how checked -> what the check found -> kept / changed / rejected.

1. **Model choice from READMEs.** AI fetched the current TIGER (JusperLee/TIGER, MIT, HF `JusperLee/TIGER-speech`, ungated) and ClearerVoice-Studio (Apache-2.0, HF `alibabasglab/MossFormer2_SS_16K`, ungated) pages and the HF API `gated` flags instead of relying on memory. Found: both ungated; `pip install clearvoice` is not possible (pins soundfile 0.12.1) so the model code was vendored. Kept.
2. **Vendoring.** AI copied only the model files into `backend/vendor/tiger_sep/` and `backend/vendor/mossformer2_ss/` with their LICENSE files and edited: TIGER's `BaseModel`/`look2hear` imports removed (weights loaded with safetensors instead), debug `print` removed, `.type(input.type())` replaced (crashes on MPS), `adaptive_avg_pool1d` moved to CPU for MPS (non-divisible sizes unsupported); MossFormer2 `torchinfo` import removed. Checked: `load_state_dict(strict=True)` passes for both ("All keys matched"); TIGER MPS output equals CPU output (max abs diff 4e-6 on peak 4.4). Kept.
3. **Speed bug found by profiling, not by guessing.** First run: 114 s for 5 s of audio (both models). AI profiled with `torch.profiler`: 85% in `aten::_nnpack_spatial_convolution`. Disabling NNPACK (scoped, `torch.backends.nnpack.flags(enabled=False)`) gave ~10x; MPS another 2-5x. Kept (the scoped flag keeps other agents' models in the same process untouched).
4. **Separation model decision** is from `eval/out/overlap.md` (script `backend/scripts/eval_overlap.py`), not from the papers' numbers. The cpWER metric (min over stream permutations of the concatenated references) was written by the AI and unit-sanity-checked on the clean case (a perfect separation gives 0%; no separation gives one stream so the 2nd reference counts as all deletions).
5. **Overlap detector.** pyannote `segmentation-3.0` (and `segmentation`, `speaker-diarization-3.1`) are gated; an anonymous download returned `GatedRepoError 401`. No token was requested. AI wrote a fallback: per 64 ms frame, YIN to find the dominant pitch, cancel it (x[t]-x[t+T0]), YIN again on the residual; a second periodic component at a non-harmonic lag means two voiced talkers. Checked on (a) the 12 synthetic mixtures with known overlap spans and (b) 190 s of single-speaker audio (`eval/clips/identity` plus the clean stems). AI's first threshold (0.35) gave zero false flags but only 51% recall; the threshold sweep (0.35/0.45/0.55 -> recall 51/67/81%, false-flagged single-speaker audio 0/4.5/21%) led to 0.45 because `separate()` re-checks candidates, so a false candidate costs compute, not a wrong caption. Kept with the limitation documented (voiced+voiced only, tuned on TTS voices).
6. **GCC-PHAT DOA.** AI wrote it; checked with synthetic delayed stereo (sign, magnitude: 4-sample delay at 0.14 m -> 38 deg expected, within 4), duplicated mono -> None, silence -> None, noise. Also verified on `say` speech with integer delays 1/3/6/-4 samples (8.8/27.3/66.7/-37.8 deg, matching asin(delay*343/16000/0.14)). A first draft of the docstring had a confusing sign note: rewritten. Changed.
7. **Unit tests** (`backend/tests/test_overlap.py`, `test_doa.py`): the AI's first `si_sdr` scale-invariance assertion compared two ~140 dB numbers and failed on float noise; changed to compare noisy estimates. The detector test uses synthetic harmonic voices with vibrato so it needs no models or network.
8. **Eval result and default pick.** `eval/out/overlap.md`, 12 mixtures: clean cpWER no-separation 43%, MossFormer2 13%, TIGER 13% (SI-SDRi 18.6 vs 15.7 dB); with synthetic reverb + 10 dB noise: 76% / 55% / 28% (SI-SDRi 5.5 vs 10.5 dB). The AI's prior was that MossFormer2 (faster, higher clean SI-SDRi) would win; the data said otherwise under degraded conditions, so the default is TIGER (`VOXLI_SEP_MODEL=mossformer2` switches). Runtimes were measured on a shared, loaded Mac (other agents running), so they are upper bounds and the TIGER/MossFormer2 gap (1.2 vs 0.6 s per audio s clean) is noisy.
9. **Limits not checked:** no real recordings, no 3+ talkers, no phone mic spacing measured, per-talker RIRs are synthetic exponential-noise tails.
