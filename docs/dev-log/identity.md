# Identity agent dev log (Card 2)

Each entry: what the AI produced, how it was checked, what the check found, kept / changed / rejected.

1. **Embedding model choice.** AI (Claude) proposed SpeechBrain ECAPA and pyannote WeSpeaker. Checked: ran both on 18 `say` voices x 8 sentences, compared same/different-speaker cosine and EER, and CPU time (table in `eval/out/identity.md`). Found: ECAPA EER 3.1% vs WeSpeaker 6.0%, 37 ms vs 55 ms per 4 s clip. Kept ECAPA; WeSpeaker rejected.
2. **Device.** AI assumed MPS would be fastest. Checked: timed CPU vs MPS on 1/2/4/6 s inputs. Found: CPU 15-44 ms, MPS 41-95 ms (per-shape overhead on short variable-length inputs). Changed: CPU default, documented in `identity/embed.py`.
3. **Test voices.** AI picked "similar-sounding" pairs by name (Eddy/Reed, Flo/Shelley). Checked: centroid cosine matrix. Found: those pairs are the same synthetic voice with different pitch (0.98 and 0.89, same as one speaker to itself), not a fair hard case. Changed: kept them only as a reported "twins" limit; real hard pairs are Junior/Kathy (0.70) and Fred/Ralph (0.57), found from the matrix.
4. **First thresholds.** AI first guessed T_HI 0.6, T_LO 0.4 from a single leave-one-out table. Checked: conversation-level run. Found: Junior and Kathy merged with confident labels (6 confident-wrong), and Karen's long segments sat at 0.47 vs Samantha (in-between zone) so she never got her own speaker until the end. Changed: added a pool so two agreeing in-between segments found a new speaker; chose thresholds from a 45-conversation sweep (T_HI 0.65, T_LO 0.40: 1.0% confident-wrong, 87% labelled). T_HI 0.75 and T_LO 0.45 were worse in the sweep and rejected.
5. **Exemplars.** AI's design scores a segment as mean of centroid and best exemplar. Checked: sweep with centroid-only vs blend vs max. Found: blend 1.5% wrong / count error 0.33, centroid-only 1.7% / 0.42, max 1.5% / 0.33. Kept blend (small gain).
6. **T_MERGE.** AI first wrote 0.90. Checked: split-half same-speaker centroid cosine (min 0.85) vs different-speaker centroids (max 0.72). Changed to 0.80 (the gap midpoint). The sweep conversations never trigger a merge at any value 0.75-1.1, so merging is covered by a unit test, not by the sweep.
7. **Unit tests** (`backend/tests/test_identity.py`, AI-written). Checked by running them, and by reading each assertion against the spec (stable ids, uncertain zone not moving centroids, short segments never create speakers, mute windows, manual and automatic merge, memory save/load/forget/off). One AI first draft had an unused variable and a no-op `np.pad`; removed. 10 pass. Real-voice test uses ECAPA on 4 voices x 6 turns.
8. **Deepgram comparison** (`backend/scripts/eval_identity.py`). AI wrote the scoring (Hungarian label mapping, flips, confident-wrong). Checked: hand-verified the mapping logic on one conversation's printed labels, and that a "?" turn is never counted as a confident error. Found nothing wrong. One bug during development: the script printed its own score keys as column headers; fixed.
9. **Voice memory privacy.** Checked by test that the file holds only name, name_source, n and the centroid vector, that it is absent unless enabled, that `forget_all` and switching memory off delete it, and the file is written 0600. Decision (AI proposed, kept): turning the toggle off deletes the file, so "off" really forgets.
10. **Limits found, not fixed:** near-identical voices; clips < 0.8 s; synthetic-only evidence. See `eval/out/identity.md`.
