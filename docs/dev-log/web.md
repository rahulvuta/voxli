# Web (Card 5) dev log

Format: what AI produced -> how it was checked -> what the check found -> kept / changed / rejected.
All code below was written by Claude (Sonnet) in this session; the checks are mine to describe honestly: build, lint, screenshots at 375x812 and 768x1024 in the built-in browser, and a real-backend run with a fake mic.

1. **Conversation store (`src/store.ts`, reducer keyed by reconnect "epoch").** AI produced a reducer that namespaces every speaker/utterance id with an epoch that increments when a reconnect opens a fresh server session. Checked by running `?mock=1&drop=1` (connection drops mid-conversation) and by killing/restarting the real backend while the page was open. Found: old captions stay, new session lanes appear next to them, no id collisions; lanes from the earlier connection were too noisy, so the tag was shortened to "earlier". Kept, tag changed.
2. **Mic capture (`src/audio.ts`, `public/pcm-worklet.js`).** AI wrote an AudioWorklet with an area-average 16 kHz resampler, Int16 interleaved 40 ms frames, and a ~0.5 s duplicated-mono detector (L/R energy ratio) before sending `hello`. Checked by feeding the browser a fake `getUserMedia` stream built from `eval/clips/stereo_cafe_4spk.wav` and `stereo_dupmono.wav` (copied temporarily into `public/`, since removed) and capturing the websocket frames. Found: stereo clip -> `hello channels:2`, 2560-byte frames (640 samples x 2 ch); duplicated-mono clip -> `hello channels:1`, 1280-byte frames; real backend returned live captions. Kept. Not verified: a real iPhone microphone (needs the phone and HTTPS cert).
3. **Websocket link (`src/net.ts`).** AI wrote reconnect with exponential backoff + jitter, hello and voice-memory replay on every open, up to ~6 s of audio buffered while offline, retry on `online`/tab-visible. Checked against the real backend (kill, wait for the Reconnecting banner, restart, confirm a new `hello` and captions kept). Found it works; initial version had a stale-closure risk on `voiceMemory`, fixed with a ref. Kept.
4. **Lanes / timeline / overlap bracket / reply + interrupt chips (`Captions.tsx`, `style.css`).** AI produced the layout. Screenshot review found three real bugs: (a) the reply chip rendered as a tall stacked pill because its class `reply` collided with the reply-bar class (renamed), (b) lanes stopped following the newest caption when a lane resized (ResizeObserver on the scroller + only real user input un-pins), (c) 4 lanes were too cramped so the active lane now grows and the YOU lane is compact. Also replaced an unrenderable glyph (⫴) and forced text presentation for the scissors glyph. Kept after fixes.
5. **Verbatim rule.** Caption text is rendered from `utterance.text` only; the per-word `conf` is mapped onto whitespace tokens of that same text (only when the counts match) for the dotted underline, so no word is ever rewritten. "Cut off", "unsure who" and reply chips are separate elements. Checked by reading the DOM output in mock mode. Kept.
6. **Accessibility.** AI added: native `<dialog>` sheets (focus trap, Esc), `aria-live=polite` announcer batched every 2.5 s with at most the 3 newest finished lines, labelled landmarks, `prefers-reduced-motion` + a settings override, high-contrast mode, shape glyphs per speaker. Checks: computed WCAG contrast for every text/surface pair with a small script (all text >= 6:1; found the border colour at 2.5:1 so raised it to >= 3.9:1), DOM dump of tab order and live-region text, screenshots. Found and fixed: `role="log"` on lanes implied a second live region (double announcements) -> changed to `role="group"`. Kept.
7. **Mock conversation (`src/mock.ts`).** AI-scripted 4-speaker conversation (self-intro with auto name + undo, introduction needing confirmation, interruption, overlap group, uncertain speaker, low-confidence words, YOU replies, catch-up, suggestions). Checked by watching it play and clicking through every flow. Found timing bug in the scheduler (a stray expression made delays wrong), fixed. Kept.
8. **Tooling note.** The built-in browser refuses the self-signed dev certificate, so I tested over plain `http://localhost` with a throwaway Vite config (deleted afterwards). `npm run build` and `oxlint` pass.
