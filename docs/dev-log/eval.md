Format: AI produced -> checked how -> found -> decision. Model: Claude (Sonnet 5.5) as agent `eval`.

1. **AI wrote `backend/scripts/make_clips.py`** (synthetic clip generator, `say` voices -> 16 kHz wav + ground-truth manifest).
   - Checked: read the code back; ran it; listed manifest overlaps; ran a GCC-PHAT on `stereo_2spk_lr` per segment.
   - Found: (a) I had left a first, buggy duplicate of the stereo-placement function in the file (dead code with a no-op branch); (b) manifest overlap windows are correct (e.g. `overlap_2spk_2s` = 2.0 s, `cafe_4spk` interruption = 1.3 s); (c) GCC-PHAT gives lag -6 samples for the left speaker and +6 for the right speaker, matching the expected 0.14 m * sin(60 deg) / 343 m/s = 5.6 samples.
   - Decision: dead function deleted (changed); everything else kept. Convention (+lag of corr(L,R) = right source) documented in the script header and manifest.
2. **AI wrote `backend/scripts/eval_asr.py`** (WER + latency + cost for 5 ASR options).
   - Checked: (a) before trusting WER, printed the word-level alignment for the cafe clips to see what the normalizer was hiding or creating; (b) first full run; (c) checked the Deepgram price against deepgram.com/pricing.
   - Found: (a) normalizer handles `$25` / `7:30` / digits correctly, errors are real recognition errors; the one error every engine makes on `cafe_4spk` is the two words "not yet" spoken during the 1.3 s interruption (overlap loss, evidence for the overlap feature); (b) local `parakeet-mlx` crashed on this machine with an MLX Metal kernel load error (`steel_gemm_fused_nax...`) on the GPU; first fix was a CPU fallback, later the pipeline agent's `MLX_METAL_GPU_ARCH=applegpu_g16s` override (docs/dev-log/pipeline.md) made the GPU path work (0.064 -> 0.026 s per audio-s); (c) my hard-coded Deepgram live price ($0.0077/min) was stale: the pricing page now shows $0.0048/min.
   - Decision: CPU fallback added for parakeet-mlx, then the GPU override adopted; price constant corrected (changed) and the Deepgram column re-run; `--only` merge flag added so one engine can be re-run without re-streaming everything.
3. **AI wrote the doc drafts** (README, DEVPOST, EVIDENCE).
